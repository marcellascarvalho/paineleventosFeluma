# Gerenciamento de Eventos — Painel Hora de Ciência

## 📁 Arquivos

- **painel-gestao-eventos.html** — Painel principal (layout original preservado)
- **docs/eventos.json** — Arquivo com eventos já inscritos
- **docs/script-eventos.js** — JavaScript para gerenciar eventos

## 💾 Como Funciona

Eventos salvos em localStorage + sincronizados com eventos.json

## 🚀 Usar no Console

```javascript
eventosManager.obterTodos()  // Ver todos eventos
eventosManager.obterEstatisticas()  // Ver estatísticas
eventosManager.exportarJSON()  // Exportar como JSON
```
